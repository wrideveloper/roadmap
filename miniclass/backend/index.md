Miniclass ini mencakup:

- Database management
- Server-side programming
- PHP programming
- Proyek praktik terintegrasi: studi kasus absensi mahasiswa (`db_absensi` / `tb_absensi`) dipakai sebagai contoh berjalan di seluruh materi fundamental — lihat [Database](/miniclass/backend/fundamental/database), [MySQL](/miniclass/backend/fundamental/mysql), [PHP](/miniclass/backend/fundamental/php), [HTML](/miniclass/backend/fundamental/html), dan [Server Side](/miniclass/backend/fundamental/server-side). Pengguna macOS: [panduan instalasi](/miniclass/backend/fundamental/instalasi-macos).
