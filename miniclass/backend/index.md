# Backend Development

Selamat datang di miniclass Backend Development! Di sini kamu akan mempelajari pengembangan backend mulai dari tingkat dasar (*fundamental*) hingga tingkat lanjut (*advance system design*).

## Materi

Miniclass ini mencakup:
- Fundamental backend development (Database, Server-side, PHP, MySQL)
- Arsitektur MVC & Framework modern (Laravel)
- Pembuatan RESTful API & Keamanan Autentikasi (Sanctum, Passport, Fortify)
- **Advance: System Design & Architecture**:
  - [Mindset & Pengenalan System Design](/miniclass/backend/system-design/01-pengenalan-system-design)
  - [Core Building Blocks Arsitektur](/miniclass/backend/system-design/02-building-blocks-arsitektur)
- **Advance: Docker & Container**:
  - [Kenapa Container Ada](/miniclass/backend/docker/01-kenapa-container)
  - [Instalasi Docker](/miniclass/backend/docker/02-instalasi-docker)
  - [Image, Container, dan CLI](/miniclass/backend/docker/03-image-container-cli)
  - [Dockerfile](/miniclass/backend/docker/04-dockerfile)
  - [Docker Compose](/miniclass/backend/docker/05-docker-compose)
  - [Volume dan Network](/miniclass/backend/docker/06-volume-dan-network)
  - [chroot](/miniclass/backend/docker/07-chroot)
  - [Namespaces](/miniclass/backend/docker/08-namespaces)
  - [cgroups](/miniclass/backend/docker/09-cgroups)
  - [Docker Itu Sebenarnya Apa](/miniclass/backend/docker/10-docker-itu-apa)

### Panduan Belajar

- **Pemula**: Mulai dari [panduan instalasi](/miniclass/backend/fundamental/instalasi) dan ikuti alur studi kasus absensi mahasiswa (`db_absensi` / `tb_absensi`) di [Database](/miniclass/backend/fundamental/database), [MySQL](/miniclass/backend/fundamental/mysql), [PHP](/miniclass/backend/fundamental/php), [HTML](/miniclass/backend/fundamental/html), dan [Server Side](/miniclass/backend/fundamental/server-side).
- **Tingkat Lanjut**: Jika sudah menguasai REST API dan CRUD, langsung pelajari modul [Advance System Design](/miniclass/backend/system-design/01-pengenalan-system-design) untuk memahami skalabilitas, Load Balancer, Redis Caching, DB Replication, dan Message Queue.
